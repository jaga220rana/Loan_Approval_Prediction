# Loan Approval Prediction

## Project Objective
Predict loan approval using machine learning models.

## Techniques Used
- Data Cleaning
- Missing Value Handling
- Label Encoding
- Feature Scaling
- SMOTE
- Logistic Regression
- Random Forest

## Evaluation Metrics
- Precision
- Recall
- F1 Score
- ROC-AUC

## Results
Random Forest performed better with higher ROC-AUC and F1 score.

## Business Insights
Credit history and applicant income were major approval factors.

## Tools Used
- Python
- Google Colab
- Pandas
- Scikit-learn
- Seaborn
